# Python - Abstract Base Classes (ABC)

This project explores advanced Object-Oriented Programming (OOP) concepts in Python. Through these tasks, we dive into abstract classes, interfaces, subclassing, and method overriding to build robust and scalable Python applications.

## Learning Objectives
* Understand and apply **Abstract Classes** to enforce class completeness.
* Grasp the concepts of **Interfaces** and **Duck Typing**.
* Learn how to extend and subclass standard base classes.
* Employ **Method Overriding** to alter base class behavior.

## Project Structure

| File | Description |
| ------ | ------ |
| `task_00_abc.py` | Defines an abstract base class `Animal` and its subclasses `Dog` and `Cat`. |
